Client Engagement · Feb 2026 – Present
Turning a two‑month reporting cycle into a five‑minute pipeline

"The report that used to take a team two months to assemble now finishes before the coffee gets cold."

2mo → 5minProcessing time
100%Ingestion coverage
FullAudit traceability

A single Spring Boot application with a ReactJS front end that replaced a slow, manual, spreadsheet-driven reporting process.

The old workflow meant engineers manually pulling screenshots out of Scopes workbooks, matching them to measurement IDs by hand, and assembling reports in PowerPoint — a process that stretched across weeks.

  • Consolidated file ingestion, Excel/PPT extraction, templating and export into one pipeline
  • Upload, processing, job-status, image-metadata and streaming download REST APIs with server-side pagination, sorting and filtering
  • Excel image extraction with automatic image-to-measurement mapping from XML
  • Comprehensive audit logging across uploads, processing triggers, downloads and admin configuration changes

My role

Owned both the backend pipeline and the ReactJS upload / status / preview UI end to end, from API design to production rollout.

Client Engagement · May 2025 – Jan 2026
Modernizing 15+ finance modules without breaking the business

"Every ledger, invoice and tax rule had to keep working exactly as before — just faster, and on a stack that could scale."

15+Modules rebuilt
24–40%Faster API response
30%Less data-entry time

End-to-end accounting workflows — Credit/Debit Notes, Balance Sheets, Purchase Journals, Invoice Reconciliation, Customer Management and Tax Configuration — rebuilt on Spring Boot and ReactJS.

The brief was reliability first: financial data can't have silent bugs. That meant heavy investment in query tuning, centralized error handling and a shared component library so every screen behaved the same way.

  • Reusable ReactJS component library (React-Bootstrap, R-Suite) for high-volume data entry and reporting screens
  • REST APIs with Spring Data JPA for Excel/PDF export, pagination, sorting and filtering across large datasets
  • Re-engineered SQL/PL-SQL into JPA/Hibernate and tuned queries for high-traffic endpoints
  • Centralized exception handling and logging with Spring AOP and SLF4J for faster issue resolution
Stack
Spring BootReactJSJPA/HibernateSpring AOPSLF4J
My role

Built modules end to end and owned the shared component library used across the finance screen suite.
